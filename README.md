# 📋 Coordinamento Ufficio Tecnico

Repository operativo per la gestione del programma attività, del cronoprogramma, delle scadenze e dell'avanzamento lavori dell'Ufficio Tecnico.

## 🧭 Navigazione rapida
- 📌 **[Programma Attività](./PROGRAMMA_ATTIVITA.md)** — Macro-obiettivi, linee operative e priorità del periodo.
- 🗓️ **[Cronoprogramma](./CRONOPROGRAMMA.md)** — Pianificazione temporale, milestone e dipendenze tra fasi.
- 📊 **[Avanzamento Lavori](./AVANZAMENTO_LAVORI.md)** — Stato sintetico delle commesse, percentuali SAL e blocchi.
- 🗂️ **Board Operativa (GitHub Projects)** — *(Inserisci qui il link alla tua board una volta creata)*

## ⚙️ Regole operative di coordinamento
1. **Apertura attività:** Ogni nuova richiesta, verifica documentale o scadenza va aperta tramite **Issues** utilizzando il template *Attività Ufficio Tecnico*.
2. **Aggiornamento stato:** I referenti aggiornano lo stato e la `% di avanzamento` direttamente nella scheda del Project entro ogni **venerdì alle 12:00**.
3. **Gestione blocchi:** Se un'attività è ferma per attese esterne (fornitori, enti, approvazioni), spostarla subito in colonna **Bloccato** e indicare il motivo nei commenti.
4. **Riunione settimanale:** Ogni lunedì mattina si revisionano esclusivamente le attività in scadenza entro 14 giorni e quelle in stato **Bloccato**.

## 🏷️ Convenzione Etichette (Labels)
- `priorita:critica` — Scadenza imminente o blocco operativo
- `priorita:alta` — Attività chiave della settimana
- `ambito:progettazione` — Calcoli, disegni, specifiche tecniche
- `ambito:documentazione` — Procedure, manuali, conformità, autorizzazioni
- `ambito:cantiere-logistica` — Sopralluoghi, trasporti, coordinamento operativo
